# 11 · Sample questions for evaluators

Questions a Block or District Education Officer (BEO / DEO) asks in a week, and what Kaaran answers. Every answer
below was produced by the running system on 1 Nov 2026 (shortened here). Ask them on the web at
**https://kaaran-vk5o.onrender.com** (type, or press 🎤 to speak) or in the WhatsApp simulator at **/whatsapp**.
Marathi, English and Marathi typed in English letters all work; the reply comes in the language you used.

> The demo district is **SYNTHETIC**: a made-up Solapur district in the real government file formats, with known
> problems planted so the analysis can be checked. Figures below are not real. Real public data (UDISE+ 2024-25,
> Solapur, aggregates only) is on the **Real data** page (/real).

**How to read the answers.** A short **direct answer** comes first (computed by code, every blue figure opens its
source file, sheet and rows). For "what needs attention" and "why" questions, **kendra cards** follow: what happened,
why (with an evidence label from fixed rules: strong evidence / no link found / not enough data) and what to do (who,
by when). The full one-page evidence brief is behind **📄 Show the full evidence brief**, with PDF buttons.

Tip: start with the role bar (**I am: DEO** for the district view, or **BEO** + a block). No login is needed.

## WhatsApp
The same questions work on WhatsApp: type, or send a voice note (Marathi or English). The bot shows what it heard
("🎤 I heard: …"), replies in the same language, and sends a short voice reply. Reply **report** / **अहवाल** for the
one-page PDF brief. Real WhatsApp uses Meta's test number, so a phone must be registered first (please contact the
team); the web simulator at **/whatsapp** runs the same bot without registration.

## Where these answers come from
- Figures: computed by code from the canonical tables, with provenance (file, sheet, rows). The AI never writes a number.
- Evidence labels and actions: fixed rules (docs/CONFIDENCE_RULES.md, docs/06_DECISION_RUBRICS.md).
- Wording: Claude writes Marathi/English sentences with placeholders, checked by a verifier; templates if it fails.
- These questions are regression-tested (tests/test_officer_questions.py, tests/test_answers.py).
